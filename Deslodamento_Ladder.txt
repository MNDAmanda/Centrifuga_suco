  └─────────────────────────────────────────────────────────────────────┘
  
  
  ┌─────────────────────────────────────────────────────────────────────┐
  │            MÁQUINA DE ESTADOS - PULSE PARCIAL (State=1)             │

  │                                                                       │
  │   Is_Running    State=1                                              │

  │           │             │                                            │

  │           │      │                                                   │
  │           │      │      Desludge_Timer.Q                            │
  │           │      └───|/|──[Set DO1_Valve = 0]                       │
  │           │              [Set DO1_Trace = 0.0]                      │
  │           │              [INC Pulse_Count]                          │

  │           │                                                          │

  │                      [Set System_Status = PARCIAL]                  │
  │                                                                       │

============================================================================
OBSERVAÇÕES IMPORTANTES:

1. Esta representação é uma equivalência lógica do programa ST
2. No CODESYS, use o editor de diagrama de contatos (FBD/LD) para implementar
3. Os timers (TON) são componentes padrão do CODESYS
4. As instruções [Set] e [Reset] representam bobinas diretas e negadas
5. As verificações [Check] representam comparações em paralelo (OR)

(* DIAGRAMA DE TRANSIÇÃO DE ESTADOS *)
(*
  
  Estado 0 (IDLE)
  ├─ DI1 > 2s ──→ Estado 1 (DESLODAMENTO PARCIAL)
  │
  └─ DI2 ─→ Retorna a Estado 0


  Estado 1 (DESLODAMENTO PARCIAL - 1 seg)
  ├─ Timer finalizado ──→ Estado 4 (WAIT)
  │                       Pulse_Count++
  │
  └─ DI2 ─→ Estado 0


  Estado 4 (WAIT - 5 seg entre pulsos)
  ├─ Timer finalizado + Pulse_Count == 3 ──→ Estado 2
  ├─ Timer finalizado + Pulse_Count == 4 ──→ Estado 3
  └─ Timer finalizado + Pulse_Count < 3 ──→ Estado 1


  Estado 2 (DESLODAMENTO PARCIAL LONGO - 6 seg)
  ├─ Timer finalizado ──→ Estado 4
  │                       Pulse_Count++
  │
  └─ DI2 ─→ Estado 0


  Estado 4 (WAIT)
  └─ Timer finalizado + Pulse_Count == 4 ──→ Estado 3


  Estado 3 (DESLODAMENTO TOTAL - 30 seg)
  ├─ Timer finalizado ──→ Estado 0
  │                       Cycle_Count++
  │                       Pulse_Count = 0
  │                       Is_Running = FALSE
  │
  └─ DI2 ─→ Estado 0

*)
